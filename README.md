# 五龙秘宝 · 5 Dragons Solo Sim

纯前端、本地存档的个人娱乐老虎机仿真版，不连接真实支付、不支持提现。

## 启动

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:5173/

## 当前功能

- 5×3 卷轴：从左至右逐列连接，可在相邻卷轴间跨任意行，不计同列竖向连接
- 黄龙、蓝龙、黑龙、红龙、白龙免费游戏选择
- 牌面包含 10、J、Q、K、A；五色神龙均可替代普通可赔付符号
- Scatter、免费游戏倍数
- 虚拟钱包：$10 / $50 / $100 / $500 模拟充值档位
- F2 或钱包按钮打开 GM 自定义充值
- 每日 500 币签到
- 余额不足时领取 1,000 币破产救济
- 本地账本：累计充值、下注、赢分、实际 RTP
- 最近 50 局历史和免费游戏状态持久化
- 音乐、旋转音效、中奖提示音

## 代码结构

- `src/config.ts`：五龙、符号、赔率、投注配置
- `src/game.ts`：纯本地从左至右连线结算引擎，不计同列竖向连接
- `src/main.ts`：钱包、账本、免费游戏、界面状态
- `src/audio.ts`：浏览器原生 Web Audio 音效
- `src/style.css` / `src/enhancements.css`：响应式主题样式

所有状态保存在浏览器 `localStorage` 的 `dragons-state` 中。此版本仅适合本地娱乐仿真，正式线上版本应重新评审随机数、支付、合规与防篡改方案。
